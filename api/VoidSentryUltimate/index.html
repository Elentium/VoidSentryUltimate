VoidSentryUltimate

Schema-based, validation-free serialization for Roblox. Build a SerdesNode from VoidSentryUltimate.Types, then use the same schema to serialize and deserialize a value. The module includes Roblox nodes for Vector3, Vector2, UDim2, Instance, CFrame, Color3, and Enum values. See the Types guide for the complete catalog and wire sizes.

Serializes a value according to a schema and returns an exactly sized buffer. Values are not validated. The caller must provide data that matches the schema and the selected node's range.

Offset: number--

Serializes a value into a new buffer after a zero-filled prefix. The returned buffer has Offset bytes before the payload. Use this when a caller will fill a packet header separately.
