# VoidSentryUltimate (pure Luau)

Validation-free, schema-driven binary serializer for pure Luau (no Roblox types).

## Install

Wally:

```toml
VoidSentryUltimate = "elentium/voidsentryultimateluau@1.0.2"
```

Pesde:

```sh
pesde add elentium/voidsentryultimateluau
```
